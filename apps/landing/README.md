# SatQuery landing (independent app)

```bash
cd apps/landing
npm install
npm run dev      # http://localhost:5174/
npm run build
npm run preview  # http://localhost:4174/
```

* Plain anchors to the workbench (`/app/projects/proj-delta` on a combined host).
* No import of `apps/web` code. Workbench builds/runs with this directory deleted.
